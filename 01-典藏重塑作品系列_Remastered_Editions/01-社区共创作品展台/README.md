# 01 · 社区共创作品展台 (Community Remastered Showcase)

> **这里汇集了全球终身学习者与开源创作者使用 ReadShift 工具链重塑的各类经典与文献排版成果。**

---

## 📖 展位开放中 · 期待你的加入

你可以使用 ReadShift 工具链挖掘并重塑任何题材的作品：
* 📜 **商业史与传记**：商界巨擘创业史、经典管理学论著
* 🔬 **科技与学术经典**：半导体开创性论文、计算机先驱回忆录
* 🏛️ **人文与历史文献**：绝版地方志、古典散文、思想家对谈

### 🌟 展台入驻原则
1. **排版视觉展示**：提交 3~5 张展示双语对齐、两级目录与移动端 EPUB 效果的高清截图；
2. **非商业与正版倡导**：完整封装的成品仅保留在个人本地私域，展位倡导支持原著正版。

👉 提交方式：查阅根目录下的 **[《CONTRIBUTING_共创指南.md》](../../CONTRIBUTING_共创指南.md)**！
