# 📚 01 · 典藏重塑作品系列 (Remastered Classic Editions)

> **“以精湛排版与双语重构，赋能蒙尘经典。”**  
> 本系列专注于将年代久远、可读性差的经典书籍与文献，通过 ReadShift 工具链重塑为具备 **Tschichold 黄金排版、艾萨克森双语交替、二创知识卡片、两级目录与防撕裂保护** 的出版级现代数字化读物。

---

## ⚖️ 本系列版权原则与分发边界声明 (Copyright & Distribution Policy)

1. **尊重原著版权与知识产权**：
   * 本系列所有作品源自公开出版的经典原著；
   * **出于对原作者与原出版机构版权的充分尊重，完整封装好的全书电子书成品（单文件 HTML 母版 / EPUB 3.0 电子书 / 精装 PDF）不在 GitHub 等公网渠道进行全量分发与传播**；
   * 完整电子书仅存放在制作者本地的 **`私域产物/`** 目录中，仅供个人技术研究、语言学习与私域非盈利交流使用。
2. **线上公网展示范围**：
   * 本展厅仅公开展示**高品质排版设计截图（Screenshots）、微片段视觉演示、两级目录架构以及排版工程化 SOP 规范**；
   * 我们强烈倡导所有读者：**如需完整阅读原著正文，请购买并支持原出版社的正版图书（Bring Your Own Book）**。
