## 求学美国（1949–1958）
- [ ] 1949 哈佛大一（全校唯一华人学生；海明威《可带走的盛宴》）
- [ ] 1950 转入 MIT 机械工程
- [ ] 1954/1955 两次博士资格考试落第
- [ ] 1955 进入希凡尼亚（Sylvania）半导体部门

## 德州仪器时期（1958–1983）
- [ ] 1958 入职德州仪器（TI）
- [ ] 与集成电路发明人基尔比（Jack Kilby）共事
- [ ] 1960s 在 TI 的职位晋升与集成电路业务管理
- [ ] 1964 获斯坦福电机博士（在职读博）
- [ ] 1972 任 TI 集团副总裁
- [ ] 1983 离开 TI

## 通用仪器 / 台湾时期（1983–1987）
- [ ] 1984 任通用仪器（General Instrument）总裁
- [ ] 1985 应台湾政府邀请出任工业技术研究院（ITRI）院长
- [ ] 1987 创办台积电（TSMC）

## 台积电时代（1987–2018）
- [ ] 1987 台积电成立，开创「晶圆代工」模式
- [ ] 1994 台积电在台湾证交所上市
- [ ] 1997 台积电赴纽交所发行 ADR
- [ ] 2005 交棒蔡力行，任董事长
- [ ] 2009 金融危机后回任 CEO
- [ ] 2018 退休卸任董事长
