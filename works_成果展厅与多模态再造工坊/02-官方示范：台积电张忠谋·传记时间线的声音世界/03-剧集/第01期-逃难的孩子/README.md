# 第 01 期《逃难的孩子》

> 台积电张忠谋 · 传记时间线的平行世界 · 第 01 期（20 分钟 · 中英双轨）
> 时间线起点：1937–42，广州 → 香港

## 本期一句话

**一个孩子的记忆里，战争不是历史，是一张张搬家的船票。**五岁的他第一次登船，还不知道这将是三次逃难、六个城市、十个学校的开始。

## 封面文案（候选）

- **主推**：时代可以推着你走，但走成什么样，从来是你自己的事。
- 备选 A：五岁那年，他第一次登上逃难的船——那是一个时代的开始。
- 备选 B：他在轰炸里学会害怕，也在害怕之后，继续往前走。

## 时间锚点与平行视角

- **传记节点**：1931 宁波出生 → 1936 迁广州 → 1937 广州大轰炸迁香港 → 1941.12.8 九龙遭攻躲入九龙酒店 → 1942 香港小学毕业 → 1942 底迁上海
- **大时代背景**：广州大轰炸（1937–38）、珍珠港事变（1941.12.7）、香港保卫战与日据（1941–45）
- **平行视角**：时代推着人走——但人在被动里长出自己的三样东西：书、观察、根
