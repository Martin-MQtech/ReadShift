## ⚖️ 版权原则与分发边界声明

1. **官方示范 01（典藏重塑系列）**：
   * 出于对原著版权的充分尊重，完整封装好的全书电子书（HTML 母版 / EPUB 3.0）**绝不在 GitHub 等公网分发传播，仅存放在本地 `私域产物/` 供个人研读**；公网展厅仅展示排版设计截图、小样与 SOP 规范，倡导支持原著正版；
2. **官方示范 02（平行叙事系列）**：
   * 故事剧本与双轨音频（MP3）**深度二创、100% 自主原创、版权独立，面向公网全量开源、开放传播与自由分发**；
3. **侵权响应机制 (DMCA Goodwill)**：
   * 本项目以学术探索与开源交流为初衷。若任何展示内容涉及权利人版权，请随时与我们联系，我们将在核实后第一时间沟通并做下架或修改处理。
