## 一、栏目是什么（定位与精神内核）

### 精神内核

**宣扬一代人艰苦奋斗、在全世界树立华人形象的精神。** 他们是举世瞩目的企业家与成功人士，他们拥抱世界、开疆拓土的精神，是栏目挖掘与学习的主要思想。

栏目本质是一部**商业故事**：聚焦那个时代的精英——因战争、求学、创业等各种原因走向世界——如何在全世界范围内**成长为世界级商界领袖**。他们的选择、历程与沉淀的经验，被提炼成当代人可消化、可吸收、可借鉴的精神。

**价值落脚点不是政治诉求，也不是社会学**——而是**个体的商业精神**：奋斗不息、不断寻找商机、不断拓宽自己的能力边界。这是栏目要挖掘与表达的核心。

**跨文明之旅**是全系列贯穿的情感主线：从一个东方第三世界进入西方国家，从一种文明完全进入另一种文明——要学习、要挑战、要适应、要自己治愈自己。商业精神的背面，是一个人在异乡完成自我重建的过程。

### 三维立体二创法（核心叙事契约，主工程确认）

二次创作（Secondary Adaptation）的叙事模型——在**商业吸引力、艺术表现力、法律合法性**三者间取平衡点的高阶二创法：

```
       ┌────────────────────────────────────────────┐
       │      外圈拓展：时代与群像（The Era）         │
       │   (Kilby / Intel三巨头 / 校园与政策推手 / 产业大势) │
       └─────────────────────┬──────────────────────┘
                             ▼
┌──────────────────────────────────────────────────┐
│      内圈交集：第三方旁白视角（The Observer）       │
│  (原书第一人称“我做了什么” → 二创“他在那一刻面对了什么”) │
└────────────────────────┬─────────────────────────┘
                         ▼
       ┌──────────────────────────────────────┐
       │      锚点：传主生平时间线（The Timeline）   │
       │       (1941 香港 → 1948 放弃作家梦 → …)   │
       └──────────────────────────────────────┘
```

1. **视角置换（First-Person → Third-Person Observer）**：原书是传主第一人称自述；二创由 AI 扮演第三方旁白/时代研究者——「他在那个时刻面对了什么，历史在那个瞬间留下了怎样的后见之明」。读者既获得对传奇命运的熟悉感与黏性，又从全新宏观视角审视选择，产生复味与解密感。
2. **内圈交集与外圈拓展的无限弹性（Intersect & Expand）**：内圈交集（重合点）= 传主人生最动人的抉择时刻（如 1948 放弃作家梦、1955 MIT 博士落第、1958 德仪良率突破），AI 旁白与自述产生对位交响；外圈拓展（离心点）= 跳出个人视角，推向群像与时代（南开师生命运、Kilby 发明集成电路的下午、Fairchild/Intel 三巨头崛起）。
3. **法律与艺术上的绝对独立性**：表达形式、叙事语言、解读视角 100% 来自 AI 与主理人的原创，完全脱离原书文本表达——法律上 100% 独立且合法的原创作品（现代纪录片与顶级自媒体标准的二次创作）。

> 本模型与既有设计同构：锚点 = 分集逻辑的「传记节点（时空坐标）」；内圈交集 = 三层叙事 ①③（他的节点 + 思想升华）；外圈拓展 = 三层叙事 ②（平行展开）。主工程侧将由 `readshift create-script` 落地（自动提取锚点 → 第三方旁白 → 编织外圈线索 → 输出原创双语脚本），`readshift build` 渲染杂志级双语 HTML + MP3。

### 写作调性设计（定稿）

> 调性公式：**艾萨克森的内核 × 史景迁的文学性 × 吴晓波的时代浪潮感 × 中文的含蓄留白**——选择它，是为了更接近我们读者的风格。

> **应用范围（主理人定）：第 01、02 期保持原调性不改；本融合调性自第 03 期起生效。**

- **中文版调性**：文学性更强、抒情克制、善用古典意象（诗经/周易/唐诗）、重留白与余韵——向史景迁/吴晓波靠拢。中文读者熟悉这段历史，所以叙述可以含蓄，让潜台词留在留白里。
- **英文版调性**：叙事流畅清晰、为语言学习者服务、重可读性与学习价值——向艾萨克森靠拢。英文读者不熟悉这段历史，需要更充分的时代背景光与更明确的叙事路径。
- **共同底线**：细节承载宏大历史；克制叙述、让事实说话；技术讲得人人可懂；人物不造神、有缺陷有温度；每集金句向「商业精神 × 跨文明之旅」收敛。

### 平行传记的创作方式

《台积电张忠谋 · 传记时间线的平行世界》是一部**由 AI（AIGC）重讲的平行传记**——从**第三方视角**重新解读与介绍这段传记故事：不是传主自述，也不是原书腔调，而是一位外部讲述者，站在平行世界里把一段人生重新拆解、对照时代、给出解读。

- **第三方视角**：以旁观者/研究者视角重讲传记，重新解读人物选择、时代机遇与命运轨迹。
- **不剧透契约**：原著中的故事只「简单提及、留白处理」，细节留给读者自己去读原版——既保持栏目独立，也为原书引流。
- **群体视角**：张忠谋是那个大时代华人精英群体中的一个——民国精英流向全世界、台湾创业者群像、全球华人科技与商业巨子。以张忠谋为入口，讲述**一个时代的平行世界**。
- **外围解读 + 交叉汇总**：真正的主体是外围的解读与交叉信息——历史、人文、社会发展的平行事件；原著只作锚点。
- **时间线骨架**：以台积电创始人张忠谋的生平与传记为时间线（1931 生 → 战乱逃难 → 求学美国 → 德州仪器 → 创办台积电 → 半导体教父）。全系列的分集逻辑、叙事权重与逐集创作蓝图，见 `系列剧集地图.md`。
- **上下册结构**：上册（1931–1998，6 章合成内容）覆盖张忠谋前半生；下册（台积电时代 → 今天）将扩展台积电影响世界的故事。**项目收尾围绕台积电成为「护国神山」及其背后的故事展开**——台湾社会与台积电的共生、世界最强芯片公司影响今天的世界，这是项目的高潮与归宿。
- **交叉信息汇总**：沿时间线汇总**历史、人文、社会发展**相关的交叉信息——同一时刻的世界在发生什么？产业、科技、思潮、社会变迁如何与一个人的命运交错？
- **双重角度**：以**科技 × 人文**的视角讲述——既讲技术逻辑与产业格局，也讲人的选择、情感与时代命运。
- **融合式写作调性（定稿）**：叙事风格是四种笔法的融合——**艾萨克森的内核**（以具体细节承载宏大历史、克制叙述让事实说话、把复杂技术讲得人人可懂、人物有缺陷不造神、主题贯穿）；**史景迁的文学性**（微历史以小见大、同理心、诗意的白描——写中国题材的西方文学史笔法）；**吴晓波的时代浪潮感**（商业史叙事的编年史 + 典型人物、「真切而激扬」的时代感）；**中文的含蓄留白**（东方情感语法——孝道、关系、面子的潜台词由第三方旁白翻译，抒情克制、余韵留白）。
- **致敬之作**：栏目以张忠谋与台积电为致敬对象，是「平行世界」式的全新创作，而非原书复述。
- **双语学习**：每集内容同时是**学英语、学历史、了解关键信息**的学习型材料——中英文稿互为平行对照（非直译），中英音频双轨，英文版独立成篇、地道表达，听众在听故事的同时磨英语耳朵、吸收历史与产业关键信息。

## 三、创作边界与内容契约

- **原创性（不用原书语句）**：所有旁白、叙事、对话均为原创撰写，不复制、不演绎任何受版权保护的书籍文本。
- **事实可查证**：叙事中的关键事实（时间、地点、人物、事件）必须有公开资料支撑，并在 `02-公开资料库/来源清单.md` 中登记来源；无来源的事实不得入稿。
- **观点可辨析**：分析与评论是栏目的灵魂，但须基于事实展开，不得编造人物言行。
- **不剧透契约 + 平行非复述**：原著故事只简单提及、留白处理；每集须有独立的「平行世界」对照或新增信息量，不做原书复述。
- **群体视角**：不止讲张忠谋一人——以他为入口，展开同时代华人精英群体（民国精英、台湾创业者、全球华人）的交叉叙事。
- **外围解读优先**：每集以「外围解读 + 交叉汇总」为主体，原著仅作时间线锚点，不做原书复述。
- **历史口径**：历史叙述以**国际英文资料共识**为准（优先参考哈佛、美国博物馆等权威机构对中国近现代史的公开记录），不采用单一政治立场的叙述版本；涉及争议处使用「据公开报道」「史料记载」等限定语。
- **避意识形态**：不提及有意识形态色彩的话题，不做政治立场评判——镜头始终对准商业与人物。
- **商业故事定位**：栏目本质是商业故事——历史与时代是背景光，镜头始终对准**人物选择、商业逻辑与领导力**；每集的「平行视角」向可借鉴的智慧提炼。
- **20 分钟标准（2026-08-13 升级）**：每期音频目标 20 分钟（±2 分钟），中英双轨各 20 分钟。文本量按此校准（中文约 5500–6500 字，英文约 3000–3600 词）。原 10 分钟标准下已交付的第 01、02 期保持原样，作为新第 02 期统稿的素材。
- **双语学习契约**：中英文稿平行对应但独立成篇（非直译）；每集须含关键信息卡（时间/人物/事件/产业逻辑），并附英文关键词汇中英对照；中英音频双轨产出，兼顾「听故事」与「学英语、学历史、了解关键信息」。

## 四、系列设计定稿（主理人确认）

- **分集逻辑**：每期 = 传记节点（时空坐标）+ 平行展开（事件/机构/群体故事）+ 平行视角思想；以张忠谋生平时间线（1931–1998）为骨架，共 **10 期 × 20 分钟**（按时间线理顺），见 `系列剧集地图.md`。
- **叙事定位（核心）**：**张忠谋是线索人物与时空坐标，不是叙事主角**。他当时并不成功——真正有引力、有吸引力的是那些重大事件。以他当时当刻的处境为锚，带听众走进围绕他、他身边、他提到的那些背后的故事——可能与他相关，也可能只是与他有链接。用他的故事**引出**我们想表达的思想，而非替他立传。
- **三层叙事结构**：① 他的节点——他在哪、在做什么、当时并不成功；② 平行展开——围绕他的时空展开的事件/机构/群体故事（叙事主体）；③ 思想升华——用他的故事引出我们想表达的思想，辅以「多年后回望」的呼应。
- **机构叙事**：借他在哈佛/耶鲁/MIT/斯坦福/德州仪器/台积电的时空坐标，讲这些机构当时的故事（校史、人物、时代风云）——机构也是叙事载体。
- **台积电双视角**：他作为创始人自有其角度；同时以第三方视角围绕台积电的成长讲不同视角的故事（政策推手、人才群像、客户生态、产业格局）。
- **镜子隐喻**：他的传记是一面镜子——以他的角度进入同一段历史，再用第三方视角重看那些大事件，是「平行世界」的深层含义。
- **五维素材**：历史、人文、科技、宗教、艺术，沿时间线取材，服务于叙事与思想表达。
- **上下册结构与收尾方向**：**上册**（1931–1998，即 6 章合成内容）覆盖第 01–10 期；**下册**（台积电时代 → 今天，主理人将提供）扩展台积电影响世界的故事。**项目收尾方向**：围绕台积电成为「护国神山」及其影响世界直到今天的故事展开——作为全世界最强的芯片公司，这是项目的高潮与归宿。下册扩展区（第 11–17 期方向草案）见 `系列剧集地图.md`。
- 开写某集前，先读 `系列剧集地图.md` 中该集的创作蓝图；蓝图与史实冲突时以史实为准并回报主理人。

## 八、内容生产 SOP

1. 选定本集「戏剧单元」与「平行视角」主线（参考 `系列剧集地图.md` 与 `01-参考内容/` 的章节索引）。
2. 资料研究：为叙事中的关键事实收集公开来源，登记至 `02-公开资料库/来源清单.md`（双源印证优先；中国近现代史优先采用国际英文资料共识）。
3. 写中文文字稿：脚本须含开场钩子 → 传记节点（本集时间线锚点）→ 平行世界对照（历史/人文/社会发展的交叉信息，科技 × 人文双视角）→ 融合调性升华（见「写作调性设计」）→ 知识延伸卡（含中英关键信息）→ 下集预告。
4. 写英文文字稿：地道英文独立创作，非直译；与中文版平行对应，同时作为**英语学习材料**（句式地道、可跟读）。
5. 生成音频：用 `tools/make_tts.py` 合成中英两版（**无参数运行即双层并发：双轨 × 段级，约 2 分钟**）；目标时长 **20 分钟（±2 分钟）**。
6. 自检 + 记录素材：核对事实来源、时长、文本与音频一致性，写入本期 `素材记录.md`。
7. 交付：本期文件夹含中英文字稿、中英音频、素材记录、README。
8. 电子书章节：文字稿交由母项目 ReadShift 引擎渲染为杂志级双语 HTML 章节（或按单文件规范封装），汇入上册电子书合集。

## 九、音频制作规范

- 引擎：edge-tts（免费）。
- 中文音色：`zh-CN-YunjianNeural`（沉稳男声）。
