# 00 · 共创指南：如何提交你的重制作品 (Community Submission Guide)

> **“每一本泛黄的老书，都值得在 AI 时代被赋予一次全新的数字生命。”**  
> 如果你使用 ReadShift 工具链重制了一部具有历史价值、思想启发或商业深度的经典读物，欢迎将你的成果提交并入驻本展厅。

---

## 🎯 展厅收录标准 (Inclusion Criteria)

为了确保展厅内作品的艺术水准与知识价值，提交的作品需符合以下基础契约：

1. **结构纯净 (D1 Cleanliness)**：中英双语对齐严整，无连续空行、未闭合标签或 OCR 乱码；
2. **出版级排版 (Typography Standards)**：符合 Tschichold 比例美学，注入双语章标题卡与二创知识卡片（Cheat Sheet）；
3. **版权合规 (Copyright Safety)**：
   * **排版成果展示**：仅提供排版视觉截图（Screenshots）、微片段演示与设计说明，不分发受版权保护的原书全量文本/PDF；
   * **AIGC 平行二创（如广播剧/播客）**：故事与脚本须为 100% 自主版权原创，可全量开源分发。

---

## 🛠️ 提交步骤四部曲 (4-Step Submission Flow)

### 第一步：准备作品资料包
在 `典藏作品展厅_Remastered_Gallery/03-社区共创作品/` 下新建你的作品目录（如 `01-你的书名/`），包含：
* **`README.md`**：作品简介、作者背景、重制亮点与 Prompt 风格说明；
* **`screenshots/`**：3~5 张展示双语排版、目录交互与移动端 EPUB 效果的高清截图；
* **`showcase_card.md`**：一句话总结该书对读者的价值。

### 第二步：本地自检与 QA 验证
确保你的源文件通过了 ReadShift 的健康检查：
```bash
# 运行 D1 源料体检
bash docs/HEALTHCHECK.sh
```

### 第三步：提交 GitHub Pull Request
1. Fork 本仓库至你的 GitHub 账户；
2. 在你的分支上添加作品目录并提交：
   ```bash
   git add 典藏作品展厅_Remastered_Gallery/03-社区共创作品/你的书名/
   git commit -m "feat(gallery): 提交社区重制作品 - 《你的书名》"
   git push origin feature/my-remastered-book
   ```
3. 向本仓库主分支（`main`）发起 Pull Request。

### 第四步：审核与正式入馆
维护团队将在 48 小时内完成排版核验，合入后你的作品将永久陈列于 ReadShift 官方展厅！
