# 第 06 期《德仪的太空竞赛岁月》

> 台积电张忠谋 · 传记时间线的平行世界 · 第 06 期（20 分钟 · 中英双轨）
> 时间线起点：1958–64，初入德州仪器 → 见证集成电路发明与太空竞赛 → 斯坦福读博 → 1964 归队

## 本期一句话

1958 年，他加入德州仪器那年，芯片还没有名字——基尔比在空实验室里点亮了人类第一块集成电路，而他在产线旁把良率从近零做到两成。三十岁，事业上升期，他把自己清零，重新背起了书包。

## 封面文案（候选）

- **主推**：他在一家赌上太空竞赛的公司里，学会了什么叫技术的信仰；而真正的强者，敢于在上升期把自己清零。
- 备选 A：那一年，芯片还没有名字——但一个时代的名字，已经写好了。
- 备选 B：一个年轻人走进达拉斯，一个发明人点亮一块锗片。几年后，它们一起被送上了月球。

## 时间锚点与平行视角

- **传记节点**：初入德州仪器（1958）→ 见证集成电路发明与公司腾飞 → 1961 TI 资助入斯坦福读博 → 1964 获电机博士、返 TI 即升任锗晶体管部总经理
