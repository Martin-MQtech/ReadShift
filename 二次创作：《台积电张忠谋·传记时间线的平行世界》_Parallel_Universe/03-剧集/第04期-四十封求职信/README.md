# 第 04 期《四十封求职信》

> 台积电张忠谋 · 传记时间线的平行世界 · 第 04 期（20 分钟 · 中英双轨）
> 时间线起点：1954–58，MIT → Sylvania → 德州仪器

## 本期一句话

**一个 MIT 的硕士，博士考了两次没过，寄出四十多封信，回音寥寥。**福特的一美元之差，把他推进了一扇他完全不了解的门——那扇门后面，是即将改变世界的半导体。

## 封面文案（候选）

- **主推**：被拒绝不是终点，是命运在给你指另一条路——只是当时没人知道，这条路通向半导体。
- 备选 A：福特开价 479，Sylvania 开价 480。他请福特加一美元，福特说不能。于是，他走进了半导体。
- 备选 B：一个博士落第的年轻人，一间旅馆的小房间，一本读不懂的书，和一位在酒吧里喝酒的老师。

## 时间锚点与平行视角

- **传记节点**：1952 MIT 学士 / 1953 硕士 → 1954–55 博士资格考试两次落第 → 1955 寄出四十余封求职信（回音寥寥）→ 福特 offer $479 因加薪被拒放弃 → 入 Sylvania 半导体部（$480）→ 锗晶体管良率改进 + 自学半导体 → 1958 判断 Sylvania「不会有大作为」，转投德州仪器
- **大时代背景**：艾森豪威尔时代、战后就业市场、晶体管革命前夜（1947 贝尔实验室发明 / 1952 四十家公司授权）、斯普特尼克时刻（1957）
- **平行视角**：被拒绝不是终点——命运用看似微不足道的碎片，悄悄拼出通往未来的路
