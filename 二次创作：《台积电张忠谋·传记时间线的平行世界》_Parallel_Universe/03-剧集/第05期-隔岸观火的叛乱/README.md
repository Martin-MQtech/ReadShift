# 第 05 期《隔岸观火的叛乱》

> 台积电张忠谋 · 传记时间线的平行世界 · 第 05 期（20 分钟 · 中英双轨）
> 时间线起点：1957–68，TI 远观硅谷

## 本期一句话

1957 年，八个年轻人抱着纸箱走出肖克利的实验室，被媒体叫做「叛逆八帮」——硅谷的故事从此有了第一章。三千公里外，一个二十六岁的年轻人刚走进德州仪器，隔着半个美国，把这场叛乱从头看到尾。

## 封面文案（候选）

- **主推**：他隔着半个美国看完的那场叛乱，后来成了他自己的剧本——只是他的舞台，在台湾。
- 备选 A：硅谷的起点不是技术，是八个人敢于离开的勇气。
- 备选 B：从仙童的「为他人做嫁衣」，到英特尔的「为自己创业」——一场改变世界的股权革命。

## 时间锚点与平行视角

- **传记节点**：1958 入德州仪器 → 隔着达拉斯看硅谷 1957 叛逆八帮出走、1968 英特尔成立 → 1972 升集团副总裁，与英特尔对垒
- **大时代背景**：硅谷创投文化起源——叛逆八帮创立仙童、洛克创投模式、英特尔三巨头（诺伊斯/摩尔/葛洛夫）与股权革命
- **平行视角**：一场叛乱，两种结局
