# ReadShift 架构排坑与血泪教训总库 (Lessons Learned Master Index)

> **定位**：本文件集中记录 ReadShift 项目自立项以来在数据处理、HTML 渲染、QA 质检、多 Agent 协作以及 EPUB 出版级工程化过程中踩过的**全部核心致命深坑与防错铁律**。
> **原则**：只记录历史问题定位、根因分析与预防办法。现行命令与执行规范一律以根目录 `执行手册.md` 为准。

---

## 🛑 一、 电子书与 EPUB 工程化深坑（2026-08-15 沉淀）

### 1. XML 实体未转义导致严格解析器白屏崩溃 (The Bare Ampersand Trap)
- **症状**：在 Apple Books 或严格阅读器打开时报错 `xmlParseEntityRef: no name`，整章白屏。
- **根因**：XHTML 采用 XML 严格解析，图注或标题中的裸 `&`（如 `Childhood & Youth`）被误认为未命名的实体引用。
- **防坑铁律**：文本注入前全局执行 `re.sub(r'&(?!(amp|lt|gt|quot|apos);)', '&amp;', text)`；打包前使用 `xml.etree.ElementTree` 强制全量断言。

### 2. 双页对开模式下的“左侧死黑”与错位 (The Spread Dilemma)
- **症状**：在 Mac/iPad 双页对开时，第一页左侧为整面纯黑，封面在右侧。
- **根因**：`cover.xhtml` 硬编码了 `height: 100vh` 与深黑背景，且 Spine 未声明居中。
- **防坑铁律**：移除固定高度与深色背景，底色全局透明；在 OPF Spine 显式配置 `properties="rendition:page-spread-center"`。

### 3. 移动端翻页卡片撕裂 (Anti-Tearing Violation)
- **症状**：手机端翻页时，一张 Cheat Sheet 卡片或图文被硬生生切成上下两截。
- **防坑铁律**：卡片与插图统一注入 `page-break-inside: avoid; break-inside: avoid;`；小节标题注入 `page-break-after: avoid;`。

## 🛑 二、 数据与源料操作深坑（来自第二章重构实战）

### 4. 对无版本控制的输出目录执行批量正则替换（不可逆灾难）
- **症状**：批量修改 `source/*.md` 时误伤跨行标签，导致 18 个页面的英文翻译大面积损毁。
- **防坑铁律**：
  1. 自动化批量修改前，必须先在沙盒层全量备份（`cp -r source source.bak`）。
  2. 严禁使用纯正则操作长距嵌套 HTML DOM，必须使用 BeautifulSoup / HTMLParser 进行节点级安全操作。

### 5. `source` 与缓存目录双写分叉
- **症状**：同一页在两个不同目录内容不一致，互相覆盖。
- **防坑铁律**：`output/chapters/chap-*/source` 是唯一人工/Agent 编辑源；严禁回写中间缓存。

## 🛑 三、 QA 门禁与模板冲突深坑

### 6. 静态 QA 脚本对动态模板（EJS/JS）的误杀假阳性
- **症状**：`template.ejs` 中的 JS 拼接代码被静态 QA 正则误判为正文锚点断头（G4-01 报错）。
- **防坑铁律**：
  1. QA 扫描前必须主动剔除 `<script>` 和 `<style>` 内容。
  2. 模板字符串中若包含标签字符，使用字符串拼接打断，防止静态分析器误判。

### 7. 修辞赏析与二创卡片中文重复
- **症状**：卡片中同一段中文出现两次。
- **根因**：源文件同时保留了裸文本和结构化的 `<span class="zh">`，渲染器双重输出。
- **防坑铁律**：二创卡片内部只保留结构化的 `.zh` 与 `.en`，坚决不保留同文裸段。

### 8. 抽屉目录缺小节但 QA 未拦截
- **症状**：点击目录抽屉只有大章，看不到二级小节。
- **根因**：动态渲染小节分支未生效，而旧 QA 只查静态 H3。
- **防坑铁律**：QA 增加 `[G4-02] 目录小节条目完整性` 断言，运行时从小节数组中提取并验证条目数 ≥ 1。

## 🛑 四、 安全与规范红线

### 9. 密钥明文进入工作脚本
- **防坑铁律**：API Key 只能从环境变量（`.env`）读取，提交前强制执行 `sk-`、Bearer 秘密扫描。
