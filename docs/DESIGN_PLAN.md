# ReadShift 视觉设计体系与顶层架构方案 (Design & Architecture System Plan)

> **设计哲学**："一本书级的阅读体验，从纸感与墨香开始。"  
> 融合西方经典书籍排版传统（Tschichold、企鹅出版社、New Yorker）与 AI 时代 Agent 交互美学。

## 一、 双重 Showcase 展示架构 (Dual-Showcase Architecture)

在 ReadShift 项目中，Showcase 并非单一形态，而是由 **“上游典藏作品截图”** 与 **“下游 100% 自主版权 AIGC 二创作品”** 共同构成的双重闭环展示矩阵：

```text
┌────────────────────────────────────────────────────────────────────────┐
│             Showcase 1: 上游旗舰作品 (典藏级双语 HTML 电子书)           │
│  · 定位：ReadShift 引擎的“开山之作”与巅峰排版艺术展示                  │
│  · 形式：高清产品视觉截图 (Screenshots Showcase) + 极短片段说明        │
│  · 契约：鉴于版权保护，仅展示精湛排版、两级目录与卡片视觉，不分发全文  │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 因果演进：有了电子书 OCR/翻译/提纯 ➔ 才有二创线索
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│             Showcase 2: 下游衍生作品 (100% 自主版权平行世界 AIGC 讲述)   │
│  · 定位：基于上游提纯的知识线索，由 AI 依照“平行叙事引擎”全新创作    │
│  · 形式：全量开源文本 + 双轨音频 MP3 + ReadShift 渲染 HTML 页面       │
│  · 契约：100% 自主版权，可全量开源发布、分发与商业化                  │
└────────────────────────────────────────────────────────────────────────┘
```

## 二、 色彩体系 (Color System)

### 2.1 书籍纸感色系（默认主题 · "墨页"）
| 角色 | 色值 | 用途 |
|------|------|------|
| 纸感底 Paper | `#faf8f3` | 全局背景（米白纸感） |
| 墨黑 Ink | `#1c1917` | 正文主色 |
| 次级墨 InkSoft | `#44403c` | 次级文字 |
| 弱化墨 InkMute | `#78716c` | 页眉/注释 |
| 分隔线 Rule | `#e7e0d3` | 边框、分隔 |
| 点睛陶土 Accent | `#9a3412` | 强调、下划线、装饰 |
| 浅陶土 AccentSoft | `#fed7aa` | 选中态、浅底 |
| 深墨块 Deep | `#292524` | 遮罩、深色块 |
| 低调银灰 Subdued | `#9298a0` | 品牌脚标、GitHub 链接 |

**设计逻辑**：借鉴企鹅出版社经典平装的克制用色——纸感底 + 墨黑 + 单一强调色，全篇不超过 4 个主角色。

## 三、 字体与版面比例 (Typography & Layout)

### 3.1 双字体引擎
- **正文 (衬线体)**：`Source Serif 4` / `Georgia` / `Baskerville` / `Songti SC`
  - 中文环境自动回退到宋体系（书感），英文阅读体验对标 New Yorker 衬线正文。
- **标题/界面 (无衬线)**：`IBM Plex Sans` / `PingFang SC`
  - 借鉴 HBR 的信息层级：无衬线标题 + 衬线正文。

### 3.2 版面比例（Tschichold 黄金规范）
- 版心最大宽度：`48rem`（约 768px，两侧留白）
- 行高：`1.9`（书籍级舒适行距）
- 段落间距：`1.75rem`
- 页边距比例参考 `2:3:4:6`（内:上:外:下）

## 四、 交互与卡片组件 (Components & Interaction)

| 元素 | 设计 | 用途 |
|------|------|------|
| **章标题卡** | 中文大标题 + 斜体英文 + ✦ 装饰线 + 著者 | 每章章首双语仪式感 |
| **两级悬浮目录** | 顶层章列表 + 下方本章小节（随动高亮） | 点章跳章首、点外闭合遮罩 |
| **Cheat Sheet** | 词条加粗 + 中文解释 + 商业造句 | 商业语汇与高阶表达积累 |
| **修辞赏析** | `<span class="rhetoric-note">` 双语卡片 | 艾萨克森式传记笔法分析 |
| **背景延伸** | `<div class="knowledge-note">` 双语卡片 | 历史、科技、机构背景补充 |
