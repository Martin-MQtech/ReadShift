## 5. 已完成并需保持的设计方案（不可回退）

这些是本项目已经定型并验证过的关键设计，接手 Agent 必须维持：

1. **每章正文开头无孤立中文大标题（2026-08-13 已修）**：第 2~6 章首源文件原来在第 1 行各带一个 `# 第X章` 或裸 `附录` 孤立中文标题（无英文配对），渲染成 `<h1>` 插在正文最前、与双语章卡重复。已全部删除，正文现在直接从第一段中文开始；章节标题统一由 renderer 注入的双语章标题卡（`.chapter-nav--start`）承担。**规则**：正文第一段之前不得再出现任何孤立中文章名大标题。接手时若发现某章 source 开头又有 `# 第X章` 之类行，按此删除。
2. **多章目录两级导航**：目录面板顶层为章列表（每章一个链接 `#chap-XX` 跳到章首），下方"本章结构"显示当前章小节（随滚动/跳转更新并高亮），序言（P1/P2/P3）并入第一章。
   - 数据：renderer 注入 `chapter_list_json`（章列表）+ `toc_json`（小节树）+ `multi_chapter`。
   - 逻辑：template `openNav()` 多章时先渲染章列表再渲染当前章小节；IntersectionObserver 随滚动更新 `currentChapterStart`。
3. **章标题卡双语装饰**（`.chapter-nav--start`）：中文大标题（Georgia 衬线，`title_zh`）+ 斜体英文副标题（Baskerville 斜体，`title_en`）+ ✦ 装饰分割线 + 著者 byline。六章及附录音标均生效。
   - **这是用户点名要求恢复的**，不可回退。
4. **二创卡片三块式**：Cheat Sheet · 商业语汇（`**term** — 中文`+`**中文解释**`+`**商业造句**，term与中文解释之间**不允许空行**，否则词卡高亮为 0）；修辞赏析（`.rhetoric-note`+`.zh`/`.en` 成对）；背景知识延伸（`.knowledge-note`+`.zh`/`.en` 成对）。中文小楷体斜体、英文 Georgia 粗斜体。
5. **QA 已重构为 HTMLParser**（`_BlockParser`+`extract_blocks`），正确处理嵌套 div，替代了脆弱的正则——不要回退到正则解析嵌套 HTML 的旧实现。

## 6. 潜在易踩的坑（来自实测教训）

- **合成前先预检各章 source**：第二章曾因 18 个文件 rhetoric-note 结构残缺（Cheat Sheet 首词条被包进未闭合 `<span>`），导致单章与合成 HTML 出现 36 个未闭合 span。现在已修复。**后续若改任一章 source，务必用 `python3 workdir/qa_gate_v3.py --chapter N` 复验 span 闭合。**
- **Cheat Sheet 词条格式**：`**term**` 行后**必须紧跟** `**中文解释**`，中间不能有空行，否则 `extractTermDetails` 读不到释义、词卡高亮变成 0。
- **一节一英**：主文本严格"一段中文紧接一段英文"，禁止连续英文、一个中文挂两个英文、跨页断句机械切分。
- **不能复制章节 HTML**：同一章只保留唯一 HTML；发现第二份按规则确认后删除。
- **离线可用**：禁止 CDN / Google Fonts / Alpine 外部依赖；图片需本地资源或 data URI。

## 7. 最终验收标准（全书"做完"的定义）

只有全部满足才算完成，缺一不可：

1. 六章单章 HTML 全部存在且 QA 0 失败（第一章的 G3-02 / G4-01 修复，见 §4.1）。
2. 六章全书单一 HTML 生成、QA 0 失败、浏览器验收通过。
3. 多章目录两级导航正确：每章可点跳转、当前章小节正确、序言并入第一章、无断头链接。
4. 每个章标题卡有中文 + 斜体英文 + ✦ 装饰线（每章起始大标题）。
5. 术语点击高亮 > 0（词卡有释义和例句）、rebook-card z 结构完整。
6. 顶栏 ☰目录 / 源起于文本想象于无限 / ReadShift·私人书房；右下角 ↑顶部；控制台 0 错误；移动端视口正常。
7. 附录仅保留权威 `附录-Appendix.html`，无冗余第二 HTML。
8. 输出命名与 `project.json` 一致；无废弃目录 / preview / 旁支残留。
9. 全部证据（构建时间、输出哈希、QA 报告、浏览器结果）写入各章及根 `执行手册.md`。
10. 未经证据齐全，不得写"制作完成"/"QA全绿"/`accepted`。
