## 本期亮点

- **平行视角**：梦想 vs 现实——父亲一句「会饿肚子」不是保守，是 1948 年金圆券恶性通胀时代教给一代父亲的血泪经验；而那个被按下的梦，几十年后以自传的方式自己醒来
- **戏剧核心**：饭桌上一句轻描淡写的话 → 金圆券房市一夜暴涨又崩盘 → 旧书店里重逢《风萧萧》→ 年过花甲写出几十万字自传
- **历史厚度**：1947–48 上海（圣约翰附中 → 南洋模范）、徐訏《风萧萧》与上海文坛的黄昏、1948 金圆券改革与徐蚌会战前夜
- **跨文明伏笔**：1948 年底迁港 → 1949 赴美——离开，是下一集《从黄浦江到查尔斯河》的起点
