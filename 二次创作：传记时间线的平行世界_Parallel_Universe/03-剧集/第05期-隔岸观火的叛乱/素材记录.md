## 二、戏剧单元与结构

- **开场钩子**：1957 秋帕洛阿尔托，八个年轻人抱着纸箱走出实验室——集体辞职，「叛逆八帮」；三千公里外达拉斯，二十六岁的他刚走进德州仪器。
- **第一幕 · 一个天才的傲慢**：肖克利 1947 晶体管/1956 诺贝尔 → 招募诺伊斯、摩尔 → 糟糕的老板（测谎、当众羞辱）→ 忍耐到极限。
- **第二幕 · 硅谷的第一声啼哭**：仙童诞生（距肖克利实验室约 12 街区）→ 诺伊斯硅基集成电路 + 平面工艺 → 半导体「黄埔军校」/「仙童之子」。
- **第三幕 · 达拉斯的旁观者**：1958 入 TI → 基尔比集成电路 → IBM 产线良率从近零到 20%+ → 「制造业的胜负写在生产线上」。
- **第四幕 · 第二次叛乱**：仙童母公司抽血、创始人无股权 → 1968 诺伊斯/摩尔再出走 → 英特尔成立（各 25 万 / 洛克募集 250 万可转换债）→ 洛克「创业者必须持股」→ 股权革命。
- **尾声 · 平行视角**：1972 升集团副总裁 → 4004 微处理器 → 摩尔定律 → 三驾马车 → 与英特尔对垒 → 金句回扣。
- **知识延伸卡**：6 条公开史实。
- **下集预告**：第 06 期《德仪的太空竞赛岁月》。
