# 第 03 期《从黄浦江到查尔斯河》

> 台积电张忠谋 · 传记时间线的平行世界 · 第 03 期（20 分钟 · 中英双轨）
> 时间线起点：1949–50，香港 → 旧金山 → 波士顿（哈佛一年 → 转学 MIT）

## 本期一句话

**一个十八岁的少年，把离开当成暂时——却走出了一条不归路。**从黄浦江到查尔斯河，从上海到波士顿，一个人的跨文明之旅，就此开始。

## 封面文案（候选）

- **主推**：他不知道，这一走，他和那个时代许多知识分子一样，把离开当成了暂时，却走出了一条不归路。
- 备选 A：十八岁，他以为这只是一次搬家——像逃难时那样。他不知道，那天的码头，是他和旧世界的最后一次合影。
- 备选 B：在哈佛，他听海明威的「流动的盛宴」；在时代里，他读懂了什么叫「暂时」。

## 时间锚点与平行视角

- **传记节点**：1948 底第三次逃难返港 → 1949.1 父亲抵港团聚 → 1949.1–7 香港七个月（办护照签证、申请哈佛）→ 1949.7 启德登泛美班机赴旧金山 → 1949 秋哈佛一年级（成绩前 10%）→ 1950 春申请转学 MIT → 1950.9 MIT 机械工程二年级
- **大时代背景**：国共易手与国民政府迁台（1949）、冷战铁幕（1946 富尔顿演说）、马歇尔计划、G.I. 法案与美国战后黄金年代
- **平行视角**：知识分子的出走——把离开当成暂时，却走出了一条不归路；跨文明之旅的起点
