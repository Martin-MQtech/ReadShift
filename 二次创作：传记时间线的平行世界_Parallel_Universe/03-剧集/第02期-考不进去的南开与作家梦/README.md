## 本期一句话

**一个没有门路的少年，怎么闯进那扇门？一个想当作家的少年，为什么放弃了梦？**——两句来自时代的话，一场少年的成人礼。

## 封面文案（候选）

- **主推**：他人生里所有的门，都是自己推开的；只有那扇文学的门，被时代轻轻关上了。
- 备选 A：一句「考不进去的」，逼他打了一场翻身仗；一句「会饿肚子」，按灭了他一个梦。
- 备选 B：关系可以给你一张门票，但只有实力，能让你一直坐在场上。

## 标题候选

1. 考不进去的南开 & 作家梦
2. 两句话，一个少年
3. 门靠本事开，梦被时代按

## 时间锚点与平行视角

- **传记节点**：1943 重庆南开（暑期班保送）→ 1947–48 上海南洋模范（作家梦被按下）
- **大时代背景**：抗战陪都重庆 → 金圆券恶性通胀、上海滩黄昏
- **平行视角**：关系 vs 实力 × 梦想与现实
